# Taller1WebMovil
Landing page de un servicio que trata de vender productos a comisión.

## Herramientas utilizadas:
- Tailwind + Tailwind Animations
- HTML + CSS + JS

## Pasos para ejecutar el proyecto
- Clonar el proyecto: ```git clone https://github.com/Xan-0/Taller1WebMovil.git```

- Instalar tailwind: ```npm install tailwindcss @tailwindcss/cli```

- Instalar tailwind-animations: ```npm install tailwind-animations```

- Abrir ```index.html``` en el navegador.
