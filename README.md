# Taller1WebMovil
Landing page de un producto, servicio o concepto.

## Sources:
- Tailwind CSS

## Pasos para ejecutar el proyecto
- Clonar el proyecto: ```git clone https://github.com/Xan-0/Taller1WebMovil.git```

- Instalar tailwind: ```npm install tailwindcss @tailwindcss/cli```

- Compilar el css de tailwind (opcional, si se necesita re-generar el css de salida):
```npx @tailwindcss/cli -i ./css/tailwind_input.css -o ./css/styles.css --watch```

- Abrir ```index.html``` en el navegador.
